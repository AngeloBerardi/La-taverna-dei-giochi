# Schede di lavoro

Una scheda = una sessione nuova = un ramo = una PR. Si eseguono con `/scheda <id>` (flusso e modelli: `docs/LAVORO.md`).

| Id | Cosa | Stato | Modello per eseguire |
|---|---|---|---|
| `V1-salvataggio-coop` | Salvare e riprendere la partita in compagnia; portare in compagnia la partita in solitario | pronta | Sonnet |
| `V2-tornei` | Tornei nelle città: duelli del capitano, premi unici | pronta | Sonnet |
| `V3-diplomazia` | Alleanze, tregue e guerre decise dal giocatore | traccia: l'architetto la completa | forte, poi Sonnet |
| `V4-regno` | Fondare un regno, vassalli, feudi, vittoria | traccia | forte, poi Sonnet |
| `V5-tattica` | Altura, bosco, formazioni, assedio a fasi | traccia | forte, poi Sonnet |
| `V6-personaggi` | Compagni che reagiscono, incarichi a catena, dialoghi coi signori | traccia | forte, poi Sonnet |
| `V7-tv-musica` | Vista TV della stanza, musica e suoni propri | traccia | Sonnet (musica: forte per il primo tema) |

«Pronta» = eseguibile così. «Traccia» = le decisioni di gioco ci sono, ma firme e prove vanno fissate dall'`architetto` leggendo il codice
(una sessione breve col modello forte: «completa la scheda V3»), poi si esegue con Sonnet. Ordine consigliato: V1, V2, V3, V4, V5, V6, V7.
